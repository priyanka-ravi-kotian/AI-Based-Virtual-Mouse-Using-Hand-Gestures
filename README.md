# AI-Based Virtual Mouse Using Hand Gestures

## Project Overview
The AI-Based Virtual Mouse Using Hand Gestures is a Python-based application that allows users to control the computer mouse using hand gestures instead of a physical mouse.

The system uses computer vision and hand tracking technology to detect hand movements through a webcam and translate them into mouse operations.

## Features
- Hand detection and tracking using MediaPipe.
- Real-time hand gesture recognition.
- Mouse cursor movement using hand movements.
- Virtual mouse control using a webcam.
- Hands-free computer interaction.

## Technologies Used
- **Python 3.11**
- **OpenCV** – Image processing and webcam access.
- **MediaPipe** – Hand detection and tracking.
- **PyAutoGUI** – Mouse movement and control.

## Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/priyanka-ravi-kotian/AI-Based-Virtual-Mouse-Using-Hand-Gestures.git
```

### 2. Navigate to the Project Folder

```bash
cd AI-Based-Virtual-Mouse-Using-Hand-Gestures
```

### 3. Install Required Libraries

```bash
pip install -r requirements.txt
```

### 4. Run the Application

```bash
python app.py
```
